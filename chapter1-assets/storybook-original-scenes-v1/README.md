# Chapter I — original five scenes, storybook color pass

These five 1672 × 941 concept images use `../revised-dark-v1/` as the direct
composition source. The castle architecture, props and scene functions remain
the same; only the rendering and palette have been reinterpreted to sit beside
the existing 2D prologue art. The chapter uses matte navy and slate blue,
subdued brass, small amber lamps and restrained red signals instead of a
bright violet dominant color.

1. `01-control-walkway.png` — dial, stairs, bridge, ring and tilted wing
2. `02-inverted-room.png` — upper and lower platforms, water and plumb line
3. `03-maintenance-shaft.png` — winch, pulleys, rope and rescue basket
4. `04-engine-room.png` — wall diagram, giant drive ring and brake
5. `05-observatory.png` — telescope, cabinets, windows and stairs

These are full-scene concept illustrations. Interactive mechanisms and
foreground occluders still need to be exported as separate Godot layers.
