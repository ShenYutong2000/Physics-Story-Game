# Chapter I castle scene concepts — storybook color pass

These five full-scene concept images retain the composition and key mechanisms of
`../castle-detail-pass-v1/`. They use the prologue's clean, flat 2D picture-book
rendering as a style reference, with darker slate-blue shadows, muted brass and
small amber or red accents. They replace the more realistic rendering of the
earlier castle concepts; they do not replace the current Godot scene layers.

| File | Preserved focal points |
| --- | --- |
| `01-control-walkway.png` | pointer dial, stairs, bridge, rotation ring and tilted wing |
| `02-inverted-room.png` | upper structure, downward water, plumb line and walkable floor |
| `03-maintenance-shaft.png` | winch, rope route, pulleys, basket and separated ledges |
| `04-engine-room.png` | mechanism diagram, drive shaft, ring gear and brake |
| `05-observatory.png` | telescope, instrument cabinets, windows and stairs |

The images are visual design references. Before implementation, export separate
far, mid, front and interactive-object layers, and check the rotating wing,
ropes, water and moving controls against the physics and chapter script.
