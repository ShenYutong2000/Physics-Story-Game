# 门闩切片重做：推近 → 全屏过肩特写

## Context

第一轮做出的门闩交互是“镜头略推近 + 屏幕中央弹出一张带边框的近景图 + 四周压暗 + 说明文字”。你的反馈是它像弹窗截图，不像真实场景。已确认的新方向：

- 镜头在场景里推近后，**溶成一个铺满整个屏幕的特写镜头**，无边框、无压暗、无标题文字。
- 特写里能看见 **Kath 的背影和伸出去的手**（过肩镜头），而不只是一只手。
- **先只重做门闩这一个切片**，你确认后再铺到窗扣、老钟、钥匙、笔记和印章。

参考的是横版剧情游戏的通用做法：日常留在横版场景里，需要动手时切到能看见角色的近距离镜头。只借鉴镜头语言，不照搬任何具体游戏的画面或内容。

**当前代码状态**：上一轮最后四处小打磨因工具报错没有写入，文件仍是 34 项测试通过时的样子，没有半截改动。那四处并入本计划。

## 新的镜头节拍（门闩）

| 阶段 | 时长 | 画面 |
|---|---|---|
| ① 接手 | 0.2 s | 按 E：Kath 向门侧挪半步、转身伸手（现有 `reach_toward`），Wick 飘到门边。 |
| ② 场景内推近 | 0.45 s | `Camera2D` 朝门闩推到约 2.2 倍。此时仍是真实大厅，没有任何叠层。 |
| ③ 溶入特写 | 0.3 s（与②的后半重叠） | 全屏门板特写淡入并继续缓慢前推（1.00 → 1.04），与镜头运动方向一致，读起来是同一次推镜。 |
| ④ 过肩就位 | 0.25 s | Kath 的背影从画面左下升入，手搭在门闩自由端。 |
| ⑤ 操作 | 玩家决定 | 拖动或按住 E。门闩、Kath 的手和身体一起移动。 |
| ⑥ 落定 | 约 0.5 s | 吸附 → 画面沿推动方向轻震 → 锁止声 → 门不再晃、门缝光合拢、风声降低 → 小字 `Door latched` 淡出 → D03 字幕。 |
| ⑦ 退回 | 0.4 s | Kath 的手收回，特写淡出，回到 2.2 倍的大厅再缓回原位；大厅里的门闩已是锁好的样子。 |

**特写里的“活”的东西**（让它不像一张静图）
- 未锁时门被风顶得间歇轻晃（画面 1–2 像素抖动 + 低沉的碰撞声，约每 3.5 秒一次），门闩越接近到位晃得越轻，锁上后停止。
- 门与门框之间一条窄窄的漏光，随门闩进度收窄，锁上后消失。
- 门闩起步有一小段“卡涩”：最初约 12 像素的拖动只让它轻微松动，之后才滑开并响起摩擦声，音高随进度略升。
- 画面随鼠标位置有 ±6 像素的轻微视差（背影层动得比门板多一点），像镜头在呼吸。

**文字**：去掉标题、说明句和整行操作提示。只保留门闩旁的方向标和角落一个很淡的 `ESC`。第一次遇到拖动操作时显示 3 秒 `Drag, or hold E`，之后不再出现。字幕移到屏幕底部，高度随文字自适应。

**退出与防卡**：Esc、鼠标右键随时退回；松手门闩停在原处；键盘按住 E 与拖动等价；无计时无失败；6 秒无进展时方向标脉动一次。这些沿用第一轮已通过测试的逻辑。

## 需要用截图迭代的地方

过肩构图没法只靠算：Kath 的背影放在画面左下，头顶不高于门闩下沿，手搭在门闩自由端，不能挡住扣座。我会先按 1.1 倍、略向左倾的摆法出图，自己看两三轮再给你。如果裁出来的背影放大后太粗糙，备选是只留手和前臂，或者由你补一张过肩背影图——届时用截图说明。

近景图里门的样子（左侧铰链式门闩 + 铭牌）与大厅里那扇门（右侧门把）并不完全一样；溶入发生在推镜途中，能盖住这个差异，但它不是同一张画。要彻底一致需要一张按大厅那扇门重画的特写，这属于后续美术，不在本轮。
